# LeanAgent 13기 1차 미팅 / OT

2026년 10월 4일 일요일 20:00–22:00, 가짜연구소 Discord Room-YL.

## 자료

- [HTML 발표자료](index.html): 16:9 슬라이드 25장. 설치와 빌드 없이 브라우저에서 엽니다.
- [구성안 및 발표자 노트](outline.md): 화면의 흐름과 진행 메모.
- [진행 및 확인 문서](preparation.md): 초안에서 보완할 내용, 진행 체크, 합의 기록 양식.
- [Lean 예제](example.lean): Mathlib 없이 실행하는 논리 예제.

## 열기

`index.html`을 브라우저에서 열면 됩니다. CSS와 JavaScript 및 assets 폴더를 함께 둡니다. 발표 자체는 외부 라이브러리, 웹 폰트, 네트워크 요청에 의존하지 않습니다. 외부 출처 링크를 누를 때만 해당 웹사이트로 이동합니다.

로컬 서버가 필요하다면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

이후 `http://127.0.0.1:8765/docs/meetings/2026-10-04-ot/`를 엽니다.

## 조작

| 기능 | 조작 |
| --- | --- |
| 이전 / 다음 | 좌우 방향키, PageUp / PageDown, 하단 버튼 |
| 다음 | Space. 버튼에 초점이 있으면 해당 버튼을 실행 |
| 처음 / 마지막 | Home / End |
| 목차 | T, 상단 목차 버튼 |
| 발표자 노트 | N, 상단 노트 버튼 |
| 전체화면 | F, 상단 전체화면 버튼. 브라우저 지원과 권한 필요 |
| 노트 / 목차 닫기 | Esc |
| PDF / 인쇄 | 상단 버튼. 모든 슬라이드를 16:9 페이지로 출력 |
| 특정 장 열기 | 주소 끝에 `#slide-9`처럼 슬라이드 번호 지정 |

11장의 단계 버튼, 12장의 오류·수정 버튼은 학습용 설명 화면을 바꿉니다. 브라우저가 Lean을 실행하지는 않습니다. 실제 검증은 `lean example.lean`으로 진행합니다.

노트는 별도 발표자 창이 아니라 화면 옆에 나타납니다. 화면 공유 전 닫아주세요. 작은 화면에서는 슬라이드를 세로로 읽을 수 있게 배치합니다.

인쇄는 현재 선택한 Lean 단계와 오류·수정 상태를 반영합니다. 11장을 완료 단계, 12장을 수정 상태로 설정한 후 인쇄하면 완성 예제를 담을 수 있습니다. PDF의 사용자 지정 용지 크기 지원은 브라우저마다 다를 수 있습니다.

## 수정 위치

- `slides.js`: 제목, 화면 문구, 발표자 노트, 출처 링크.
- `styles.css`: 레이아웃과 글자 크기.
- `deck.js`: 이동, 목차, 노트, Lean 단계 설명.
- `outline.md`: 구성과 진행 메모의 문서판. `slides.js`를 수정하면 함께 갱신합니다.

실제 지원 질문과 운영 기준을 확인한 뒤 보완할 초안입니다. 연락처는 포함하지 않았습니다.

빌더 소개는 3장입니다. 경력, 관심 분야와 대회 성과를 간단히 소개합니다. Kaggle 대회 기록을 클릭하면 원본 비율로 확대합니다. 확대 화면에서는 Esc로 닫은 뒤 슬라이드를 이동합니다.

## 러너 링크드인 연결

`slides.js` 상단의 `OT_RUNNERS`에서 각 이름 옆 `linkedin: ''`에 전체 프로필 주소를 입력합니다. 저장하고 새로고침하면 해당 이름이 새 탭으로 열리는 링크가 됩니다. 주소가 비어 있는 이름은 클릭 시 미등록 안내만 표시합니다. 현재는 사용자가 제공한 러너 6명의 프로필 주소를 연결했습니다.

6장은 빌더의 프로젝트 기획 배경입니다. 공식 소개인 5장과 구분하고, 연구 질문은 7장에서 이어집니다.

9장에서 Lean과 Mathlib의 개념과 역할을 설명하고, 10–12장에서 Lean 예제를 살펴봅니다.

대회 소개는 13–17장입니다. 공식 Home·Benchmark·규칙·점수 계산 화면의 캡처를 사용하며, 클릭하면 원본 화면이 확대됩니다. 18장에서는 시즌 전체 흐름과 단계별 결과물을 설명합니다. 규칙과 일정은 2026-10-03 확인 기준입니다.

질문과 답변은 19–20장입니다. 19장은 러너의 세 질문(수학 에이전트의 목표, 장기 확장, 확률모델·Gaussian Mixture 적용)과 빌더의 답변을 같은 형식으로 함께 다룹니다. 20장은 참여 방식과 결과에 대한 네 가지 논의 질문입니다.

23장은 자료 공유와 모임 후 정리·취합 방식을 함께 정하는 논의 페이지입니다. 22장 스터디 규칙 다음, 24장 서로의 활동 연결하기 앞에 배치했습니다.
