## 운영 논의 초안

### 작은 작업과 역할

첫 2주 동안 주 담당 작업과 함께 볼 작업을 하나씩 고르는 방식으로 제안합니다. 현재 가능한 기여와 배우고 싶은 역할을 함께 고려합니다. 고정 직책으로 확정하지 않고 경험 후 조정합니다.

### 자료 공유와 참여

금요일까지 초안 링크 공유, 각자 15–20분 주간 학습 공유, 링크드인·블로그 성과에 좋아요와 댓글로 응원하기를 제안합니다. 진행이 막힌 경우 조기 공유하고 실패한 시도와 실행 방법도 기록합니다. 모임 마지막에 다음 주 작업과 담당자를 정하고, 종료 후 Discord에 남깁니다. 팀이 합의한 내용만 운영 규칙으로 확정합니다. 바쁜 시기의 작업량도 함께 조정합니다.

### 코드 리뷰와 머지

러너가 코드 변경을 PR로 올리고, 정기 모임에서 함께 리뷰한 뒤 머지합니다. 급한 기능은 카톡이나 Discord에서 먼저 소통하고 리뷰·머지합니다.

### 저장소

LeanAgent와 대회용 private 저장소를 따로 관리하고 문서로 연결하는 방식을 우선 검토합니다. Git submodule은 의존성과 권한 구조상 필요가 확인되면 도입합니다. 접근 권한과 대회 기간의 공개 범위는 팀과 공식 규칙을 확인해 정합니다.

### 소통과 공개 기록

카톡은 상시 소통, Discord는 모임과 공지, GitHub는 코드·실험·작업 기록, 가짜연 페이지는 활동 기록과 외부 자료 링크를 모으는 용도로 제안합니다. 공개 프로필 연결과 글·리액션 공유는 자율 참여입니다.

연락처와 개인 성향 메모는 발표자료와 공개 저장소에 넣지 않습니다.

## 대회 공식 안내 확인 기록 · 2026-10-03

- 공식 사이트: [Lean Refactor Arena](https://huggingface.co/spaces/delta-lab-ai/lean-refactor-arena). Home, Benchmark, Tracks & Rules 탭을 직접 읽고 캡처했습니다.
- Warm-up 15문제, 2026-11-01 본 50문제 공개, 11-08 제출 마감, 11-22 우승자 발표.
- Track 1: 문제당 API 비용 ≤ US$3. 공개 정가 기준으로 재시도·폐기 후보까지 모든 호출을 계산합니다.
- 문제별 길이 감소율·heartbeat 감소율·버전 호환성의 평균을 계산한 뒤 모든 문제 점수를 평균합니다. 미제출·검증 실패 등의 문제도 0점으로 평균에 포함됩니다.
- 공식 비교 예시는 Warm-up 문제가 아닌 miniF2F `amc12_2001_p21`입니다. 홈페이지에 3줄 / 4,331,226 heartbeats와 130줄 이상 / 157,079 heartbeats를 제시합니다. 팀의 자체 재측정 결과로 소개하지 않습니다.
- 증명 JSONL과 재현 코드는 대회 사이트, 보고서는 [OpenReview](https://openreview.net/group?id=NeurIPS.cc/2026/Workshop/VERICODEGEN)에 별도로 제출합니다.
- 보고서 공식 양식: [Overleaf](https://www.overleaf.com/read/fhmwmtrgwkmc#4d5413). 본문 3–9페이지, 참고문헌·부록 제외, single-blind이며 익명화하지 않습니다.
- 필수 본문 제목·순서: Approach → Models → Budget accounting → Reproduction.
- 코드에는 최상위 README와 정확한 재현 절차, 고정한 Lean toolchain 및 의존성 revision을 포함합니다. `.zip` 또는 `.tar.gz`로 제출합니다.
- 페이지의 Tech report & code 설명은 실행 명령을 코드 README에 두라고 안내하고, 필수 항목 안내는 보고서 본문에도 Reproduction 섹션을 요구합니다. 둘 다 준비하고 최종 양식의 요구사항을 확인합니다.
